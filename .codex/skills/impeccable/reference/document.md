# ima-app のUI設計情報の整理

[SKILL.md](../SKILL.md)と[文書の更新方針](../../../../docs/devlop/development.md#文書の更新)に従う。

- 対象画面と既存テーマ・共通部品から、色・余白・文字・状態表示の実装を確認する。
- コードから分かる値の一覧を別の仕様書へ転記しない。根拠のファイルを会話で示す。
- 実装からは分からない製品上の意図・決定を文書化する場合は、既存の[製品仕様](../../../../docs/product.md)へ反映する。
- 未決のデザイン案や作業計画はGitHub Issueで管理する。文書整理だけで起票しない。
- ルートの `DESIGN.md`、`PRODUCT.md`、`.impeccable/design.json` を追加しない。
